#Система контроля посещаемости

## TC-01. Запуск приложения
| Поле | Описание |
|---|---|
| ID | TC-01 |
| Функция | Запуск приложения |
| Предусловие | Приложение установлено на эмуляторе/устройстве |
| Шаги | 1. Запустить приложение. 2. Дождаться загрузки главного экрана. |
| Ожидаемый результат | Приложение открывается, отображается главный экран с названием и кнопками, краша нет. |
| Фактический результат | Приложение запускается, виден главный экран |
| Статус | Выполнено |

## TC-02. Отображение главного экрана
| Поле | Описание |
|---|---|
| ID | TC-02 |
| Функция | Главный экран |
| Предусловие | Приложение запущено |
| Шаги | 1. Открыть приложение. 2. Проверить наличие элементов: название приложения, кнопки «Студенты», «Отметить посещаемость», «Статистика». |
| Ожидаемый результат | Все элементы видны, не обрезаны, расположены корректно. |
| Фактический результат | Главный экран хорошо виден, все кнопки на месте |
| Статус | Выполнено |

## TC-03. Реакция кнопок главного экрана
| Поле | Описание |
|---|---|
| ID | TC-03 |
| Функция | Навигация |
| Предусловие | Приложение запущено, главный экран открыт |
| Шаги | 1. Нажать «Студенты». 2. Вернуться назад. 3. Нажать «Отметить посещаемость». 4. Вернуться. 5. Нажать «Статистика». 6. Вернуться. |
| Ожидаемый результат | Каждая кнопка открывает соответствующий экран-заготовку; приложение не завершается аварийно; возврат назад работает. |
| Фактический результат | Каждая кнопка реагирует на нажатие, открывается нужный раздел (на данный момент они "в разработке", но кнопки работают)|
| Статус | Выполнено |
