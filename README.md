# Система контроля посещаемости студентов

**Стек технологий:** Kotlin, Android Studio, XML, Room (SQLite), Git.
**Минимальные требования:** Android 7.0 (API 24) и выше.

## Как запустить проект:
1. Клонируйте репозиторий: `git clone <ссылка>`
2. Откройте папку проекта в Android Studio.
3. Дождитесь окончания Gradle Sync.
4. Подключите эмулятор или реальное устройство.
5. Нажмите кнопку **Run 'app'** (зеленый треугольник).

---

## Инструкция пользователя (как работать с приложением):

### 1. Добавление студентов
- На главном экране нажмите **«Студенты»**.
- Введите Фамилию, Имя и Учебную группу.
- Нажмите **«Добавить студента»**. Студент появится в списке ниже.
- *Примечание:* Приложение не позволит добавить студента с пустыми полями или дубликат.

### 2. Создание занятия и отметка посещаемости
- На главном экране нажмите **«Отметить посещаемость»**.
- Выберите группу из выпадающего списка.
- Нажмите **«+ Создать занятие»**, введите дату (в формате ГГГГ-ММ-ДД) и тему.
- Выберите созданное занятие из списка. Появится список студентов.
- Для каждого студента выберите статус: **Присутствовал**, **Отсутствовал** или **Опоздал**.
- Внизу экрана отобразится живая статистика по текущему занятию.
- Нажмите **«Сохранить отметки»**, чтобы сохранить данные в базу.

### 3. Просмотр статистики
- На главном экране нажмите **«Статистика»**.
- Выберите группу или конкретного студента.
- При необходимости выберите период (по умолчанию — текущий месяц).
- На экране отобразятся: количество занятий, процент посещения, число пропусков и опозданий.

---
## Ограничения
- Приложение работает только с локальной базой данных (Room) на одном устройстве.
- Для работы не требуется подключение к интернету.
- Все персональные данные вымышлены и используются исключительно в учебных целях.
