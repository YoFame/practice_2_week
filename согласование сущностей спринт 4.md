### **Сущность Student (студент)**


| Поле | Тип | Обязательное | Комментарий |
| :--- | :--- | :--- | :--- |
| `id` | Long | Да | Уникальный идентификатор, генерируется автоматически (PK) |
| `fullName` | String | Да | ФИО студента |
| `group` | String | Да (или нет — уточните у команды) | Номер/название группы |
 

 
### **Сущность Attendance (отметка посещаемости)**
Это запись «студент X был на занятии Y со статусом Z».

| Поле | Тип | Обязательное | Комментарий |
| :--- | :--- | :--- | :--- |
| `id` | Long | Да | Уникальный идентификатор записи (PK) |
| `studentId` | Long | Да | Ссылка на Student.id (внешний ключ) |
| `lessonId` | Long | Да | Ссылка на Lesson.id (внешний ключ) |
| `status` | Enum/String | Да | `PRESENT`, `ABSENT`, `LATE`, `EXCUSED` (присутствовал / отсутствовал / опоздал / уважительная причина) |
| `markedAt` | Long (timestamp) | Да | Когда отметили (полезно для истории) |
 

 
### **Сущность Lesson (занятие)**
 

| Поле | Тип | Комментарий |
| :--- | :--- | :--- |
| `id` | Long | PK |
| `date` | Long | Дата занятия (timestamp) |
| `subject` | String | Название предмета (опционально) |
 

 
### **Сценарий: первый запуск приложения**
**Условие:** Пользователь впервые открыл AttendanceControl, в базе нет ни одного студента.

**Ожидаемое поведение:**

Главный экран открывается без ошибок и без зависаний.

Если на экране «Студенты» — отображается **пустой список** (никаких строк), кнопка «Добавить студента» доступна.

Приложение **не падает** при попытке открыть экран «Отметить посещаемость» — там должно быть сообщение «Нет студентов для отметки» или пустой экран с подсказкой.

При открытии экрана «Статистика» — **0й**

 
### **Сценарий: пустая база (пользователь удалил всех студентов)**
**Условие:** Все студенты удалены.

**Ожидаемое поведение:**

Список на экране «Студенты» — пуст (но приложение работает, кнопка добавления активна).

Отметки посещаемости **тоже должны быть удалены** (каскадное удаление) — иначе при добавлении нового студента с новым `id` старые «висячие» отметки могут показаться. Проверьте это на тест-кейс

Экран «Статистика» показывает нули или «Нет данных», **не падает** с ошибкой деления на ноль (частая ошибка — средний процент посещаемости считать при 0 студентов).

Экран «Отметить посещаемость» показывает сообщение «Список студентов пуст».
