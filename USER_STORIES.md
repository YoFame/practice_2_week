# Требования к проекту: Система контроля посещаемости

## Проблема
Преподаватель ведёт несколько учебных групп с большим числом студентов. Учёт посещаемости ведётся вручную, поэтому:
- Медленно открывать нужную группу на занятии.
- Нет быстрого способа увидеть, сколько студентов присутствовало на занятии.
- Процент посещения для отчётности считается вручную.
- Чтобы понять, что студент пропустил, приходится листать записи.

## User Stories и критерии приёмки

| User Story | Критерии приёмки |
|---|---|
| **US-1.** Как преподаватель, я хочу создать учебную группу и добавлять в неё студентов, чтобы быстро открывать нужный список занятий. | 1. Можно создать группу с названием.<br>2. Пустое название не сохраняется.<br>3. Студент добавляется в группу.<br>4. Список группы открывается не больше чем за 2 нажатия из главного меню. |
| **US-2.** Как преподаватель, я хочу создать занятие с датой и темой выбранной учебной группы, чтобы привязать отметки конкретному занятию. | 1. Выбирается учебная группа, дата и тема.<br>2. Занятие сохраняется и открывается для отметки посещаемости.<br>3. Дата и тема видны в истории посещаемости. |
| **US-3.** Как преподаватель, я хочу отметить статус студента в 1–2 нажатия, чтобы не тратить время занятия. | 1. Доступны три статуса: присутствовал, отсутствовал, опоздал.<br>2. Комментарий необязателен.<br>3. Изменения сохраняются.<br>4. Статус виден в списке студентов занятия. |
| **US-4.** Как преподаватель, я хочу видеть статистику посещения учащихся, чтобы быстро оценить картину. | 1. Показаны три числа: присутствовало, отсутствовало, опоздало.<br>2. Число присутствовавших = кол-во студентов со статусом «присутствовал» + «опоздал».<br>3. Числа обновляются сразу после изменения статуса.<br>4. Сумма трёх чисел равна числу студентов в группе. |
| **US-5.** Как преподаватель, я хочу видеть историю посещения студента, чтобы понимать, что он пропустил. | 1. Список занятий по датам: дата, тема, статус, комментарий.<br>2. Сортировка по дате.<br>3. Пропуски и опоздания визуально отличимы от присутствия.<br>4. История открывается из карточки студента. |
| **US-6.** Как преподаватель, я хочу видеть % посещения группы за период, чтобы не считать вручную. | 1. Можно выбрать период (по умолчанию текущий месяц).<br>2. Показан процент посещения по группе.<br>3. Показано число пропусков и опозданий по каждому студенту.<br>4. Список студентов сортируется по числу пропусков. |

## Описание экранов

### Главное меню
- **Назначение:** точка входа, навигация по основным разделам.
- **На экране:** название приложения, кнопки: «Студенты», «Отметка посещаемости», «Статистика».
- **Действия:** переход в любой из трёх разделов.
- **Переходы:** Студенты, Отметка посещаемости, Статистика.

### Студенты
- **Назначение:** ведение учебных групп и списков студентов.
- **На экране:** список учебных групп, внутри группы — список студентов (ФИО); кнопки: добавить группу, редактировать, удалить.
- **Действия:** создать/переименовать/удалить группу; добавить/редактировать/удалить студента (ФИО + группа); открыть карточку студента.
- **Переходы:** Карточка студента, Главное меню.

### Отметка посещаемости
- **Назначение:** создание занятия и отметка статусов студентов.
- **На экране:** выбор занятия (учебная группа + дата + тема), список студентов выбранной группы, у каждого переключатель статуса (присутствовал, отсутствовал, опоздал), поле комментария (необязательно), статистика, кнопка «Сохранить».
- **Действия:** создать занятие, отметить статус каждому студенту, добавить комментарий, сохранить отметки.
- **Переходы:** Главное меню.

### Статистика
- **Назначение:** отчётность по посещаемости.
- **На экране:** выбор объекта (группа или студент), выбор периода (по умолчанию текущий месяц), сводка по группе (процент посещения, число пропусков и опозданий, кол-во присутствовавших), список студентов, отсортированный по числу пропусков, история по студенту (список занятий).
- **Действия:** переключить группу/студента, выбрать период, просмотреть сводку и историю.
- **Переходы:** Главное меню, из карточки студента.
