## TC-04. Проверка работы пустой базы данных
| Поле | Описание |
|---|---|
| ID | TC-04 |
| Функция | Инициализация Room (пустая база) |
| Предусловие | Приложение установлено и запущено впервые |
| Шаги | 1. Открыть раздел «Студенты». 2. Проверить отсутствие данных. |
| Ожидаемый результат | Отображается сообщение о том, что список пуст (Empty State). Приложение не вылетает (нет краша). |
| Статус | Ожидает проверки |

## TC-05. Сохранение данных при перезапуске (Главный тест Room)
| Поле | Описание |
|---|---|
| ID | TC-05 |
| Функция | Постоянное хранение данных |
| Предусловие | В базе есть хотя бы один студент и создано занятие с отметками |
| Шаги | 1. Полностью закрыть приложение (смахнуть из недавних). 2. Открыть приложение снова. 3. Зайти в «Студенты» и «Отметить посещаемость». |
| Ожидаемый результат | Все ранее добавленные студенты и выставленные отметки остаются на своих местах. |
| Статус | Ожидает проверки |

## TC-06. Удаление из базы данных
| Поле | Описание |
|---|---|
| ID | TC-06 |
| Функция | Удаление записей (Room) |
| Предусловие | В базе данных есть студент |
