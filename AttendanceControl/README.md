# AttendanceControl — Система контроля посещаемости студентов

Мобильное Android-приложение на Kotlin для преподавателя или куратора группы: учёт посещаемости студентов колледжа (присутствовал / отсутствовал / опоздал), история отметок и простая статистика. Приложение работает локально на одном устройстве.

**Состояние:** спринт 2 из 6 — Студенты и учебные группы.

## Технологии

- Kotlin, Android Studio, Android SDK (minSdk 24, compileSdk 34)
- XML-разметка, Activity, RecyclerView (View-based интерфейс)
- JUnit — модульные тесты
- Git — контроль версий; Markdown — документация

## Требования

- Android Studio (Otter 3 или новее) с встроенной JDK; проект использует AGP 9.0 и Gradle 9.1 (работают с Java 17–25)
- Эмулятор или устройство с Android 7.0 (API 24) и выше

## Открытие и запуск

1. Клонировать репозиторий или распаковать архив проекта.
2. В Android Studio выбрать **File → Open** и указать папку `AttendanceControl`.
3. Дождаться синхронизации Gradle (при необходимости Android Studio создаст `gradle-wrapper.jar` и `local.properties`).
4. Выбрать эмулятор/устройство и нажать **Run ▶**.
5. Тесты: **Run Tests** для папки `app/src/test` или `./gradlew test`.

## Экраны

- **Главный экран** — название приложения и кнопки перехода к разделам.
- **Студенты** — добавление студента (фамилия, имя, группа), список, удаление с подтверждением.
- **Отметить посещаемость** — заглушка, будет реализовано в спринте 3.
- **Статистика** — заглушка, будет реализовано в спринте 5.

## Ограничения

- Локальное использование на одном устройстве, без синхронизации и авторизации.
- Хранятся только вымышленные данные студентов (персональные данные в репозиторий не добавляются).
