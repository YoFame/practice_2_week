# Тест-кейсы — «Система контроля посещаемости студентов»

Состояние на конец **спринта 2**.

Столбец «Результат» заполняется при прогоне: ☑ пройден / ☒ не пройден / ☐ не выполнялся.

| ID | Спринт | Функция | Предусловие | Шаги | Ожидаемый результат | Результат |
| --- | --- | --- | --- | --- | --- | --- |
| TC-01 | 1 | Запуск приложения | Приложение установлено на эмуляторе/устройстве | Запустить приложение | Приложение запускается без аварийного завершения | ☐ |
| TC-02 | 1 | Главный экран | Приложение запущено | Открыть главный экран | Отображаются название и три кнопки: «Студенты», «Отметить посещаемость», «Статистика» | ☐ |
| TC-03 | 1 | Реакция кнопок | Открыт главный экран | Нажать каждую из трёх кнопок; вернуться кнопкой «Назад» | Открывается соответствующий экран; возврат на главный экран работает | ☐ |
| TC-04 | 2 | Добавление студента | Открыт экран «Студенты» | Ввести фамилию «Иванов», имя «Пётр», группу «ИС-21»; нажать «Добавить студента» | Студент появился в списке; показано «Студент добавлен»; поля фамилии и имени очищены | ☐ |
| TC-05 | 2 | Пустые поля | Открыт экран «Студенты» | Оставить одно или несколько полей пустыми; нажать «Добавить студента» | Студент не добавлен; показано «Заполните все поля: фамилия, имя и группа» | ☐ |
| TC-06 | 2 | Пробелы вместо текста | Открыт экран «Студенты» | Ввести в поля только пробелы; нажать «Добавить студента» | Студент не добавлен; показано сообщение о пустых полях | ☐ |
| TC-07 | 2 | Повторная запись | В списке есть «Иванов Пётр», группа «ИС-21» | Добавить студента с теми же данными (в том числе другим регистром) | Дубликат не добавлен; показано «Такой студент уже есть в этой группе» | ☐ |
| TC-08 | 2 | Удаление студента | В списке есть студент | Нажать «Удалить»; подтвердить удаление | Студент исчез из списка; остальные записи не изменились | ☐ |
| TC-09 | 2 | Отмена удаления | В списке есть студент | Нажать «Удалить»; выбрать «Отмена» | Студент остался в списке | ☐ |

## Автоматические тесты (JUnit)

Запуск: Android Studio → правый клик по папке `app/src/test` → Run Tests, либо `./gradlew test`.

- `StudentValidatorTest` — 6 тестов: корректные данные, пустые поля, пробелы, дубликаты, нормализация
